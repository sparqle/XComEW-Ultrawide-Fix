// Fix screen-to-UI and UI-to-screen coordinate mapping
//
// Replace:
//   UIFxsMovie.ConvertNormalizedUICoordsToScreenCoords (UI-to-screen)
//   XComInputBase.ConvertUIPointToScreenCoordinate (bad name, does screen-to-UI)
//   UIWorldMessageMgr.UpdateMessages (Was missing call to UI-to-screen conversion for multi-message update)
//
// Map between screen pixels and the game's 1280x720 UI canvas using
// the smaller width/height scale and centering on both axes:
//
//     Scale = Min(ScreenWidth / 1280.0, ScreenHeight / 720.0)
//     OffsetX = (ScreenWidth - 1280.0 * Scale) * 0.5
//     OffsetY = (ScreenHeight - 720.0 * Scale) * 0.5
//
//     Screen to UI (after converting normalized coordinates to pixels):
//         UIX = (ScreenX - OffsetX) / Scale
//         UIY = (ScreenY - OffsetY) / Scale
//
//     UI to screen:
//         ScreenX = UIX * Scale + OffsetX
//         ScreenY = UIY * Scale + OffsetY
//
// This keeps both conversions consistent, prevents horizontal stretching,
// and preserves 16:9 behavior.
// ------------------------------------------------------------
